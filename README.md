# 🎮 Adnan Same Shop

### Online & Offline Game Shop – UI Design Project

Adnan Same Shop is a modern gaming e-commerce website concept designed for gamers who want to explore and purchase both online and offline games.

The project focuses on a premium gaming experience with attractive visuals, modern layouts, and a user-friendly interface.

## 🎨 Design Tool
- **Figma** – UI/UX Design
- Frontend UI Concept
- Responsive Layout Design

## ✨ Key Features

- Modern Gaming-Themed UI
- Attractive Game Banners and Images
- Online Game Category
- Offline Game Category
- PC & Mobile Gaming Sections
- Game Details and Product Cards
- User-Friendly Navigation
- Responsive Website Layout Concept
- Modern E-commerce Interface

## 🎯 Project Goals

- Create a professional gaming marketplace UI.
- Provide an attractive browsing experience.
- Organize online and offline games.
- Design a user-friendly shopping interface.
- Support both PC and mobile screen layouts.
